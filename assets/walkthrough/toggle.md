# Turn the proxy on and off

The status bar shows the proxy's state. Click it to turn the proxy on or off.

| Status bar              | Meaning                                           |
| ----------------------- | ------------------------------------------------- |
| `Proxy: Not Configured` | No profile yet; a click offers to set one up      |
| `Proxy: OFF`            | Proxy Toggler sets no proxy                       |
| `Proxy: ON`             | Your only profile is on                           |
| `Proxy: Work`           | With two or more profiles, the profile that is on |

A warning icon means VS Code's proxy settings hold a proxy that matches no profile. Open the
switcher to save it as a profile, or to turn it off.
